# Product

> **用途**：记录 `CourseMotion Studio` 的产品承诺、目标用户、核心场景、用户旅程、成功标准和演示证据。

## 产品承诺

CourseMotion Studio（课动工坊）帮助课程设计者、培训顾问和内容生产者，把已有课程大纲继续加工成课程脚本、视频分镜、视觉系统、素材 Prompt 和导出素材。

本项目不从零生成课程大纲；它服务于“大纲已经由其他 Skill 或人工产出之后”的后处理工作流。

## 目标用户

| 用户 | 需求 | 成功状态 |
|------|------|----------|
| 培训课程设计者 | 把已有大纲快速转成可授课脚本和视频生产结构 | 能导出 Course JSON、Script、Storyboard 和 Markdown |
| 企业内训顾问 | 统一课程脚本、视觉风格和素材需求 | 每个节点可编辑、可重新生成、可校验 |
| 视频课程制作人员 | 从课程内容得到分镜、画面描述和素材 Prompt | 能把 Storyboard 作为 PPT、动画和视频生产前置材料 |

## 核心场景

| 场景 | 用户 | 触发条件 | 期望结果 |
|------|------|----------|----------|
| 大纲后处理 | 课程设计者 | 已有课程大纲文本或 Word 文档 | 生成结构化 Course JSON |
| 脚本生产 | 培训顾问 | Course JSON 已确认 | 生成讲师讲解脚本 |
| 视频前期 | 视频课程制作人员 | Script JSON 已确认 | 生成 Storyboard、视觉系统和素材 Prompt |
| 交付导出 | 任意用户 | 节点内容已生成或编辑 | 下载 JSON / Markdown 文件 |

## 用户旅程

### 第一个有用结果

1. 用户粘贴课程大纲文本，或上传 `.docx`。
2. 系统解析大纲并生成 Course JSON。
3. 用户继续生成脚本、分镜、视觉系统和素材 Prompt。
4. 用户导出 JSON 或 Markdown，用于后续 PPT、动画和视频生产。

### 常见重复使用

1. 进入工作区，选择当前节点。
2. 查看、编辑或重新生成节点内容。
3. 校验内容是否存在，导出阶段性产物。

## Before / After

| 之前 | 之后 |
|------|------|
| 课程大纲停留在文本或 Word，后续脚本、分镜、视觉和素材需求需要手工拆解 | 大纲被转换为可编辑的结构化工作流数据，并可导出给后续制作环节 |

## 成功标准

- 用户可以输入文本大纲或上传 `.docx`。
- 系统可以产出 Course JSON、Script JSON、Storyboard JSON、Visual System JSON 和 Asset Prompt JSON。
- 用户可以在前端查看和编辑每个节点内容。
- 用户可以导出 JSON 和 Markdown。
- PPTX、Remotion、HyperFrames、字幕/TTS 功能有清晰占位，但第一阶段不完整实现。

## 非目标

- 第一阶段不做从零课程大纲生成。
- 第一阶段不完整实现 PPTX 自动排版、Remotion 视频渲染、HyperFrames 动画代码、TTS 配音和字幕时间轴。
- 第一阶段不做账号系统、多用户协作、云端存储和支付。
